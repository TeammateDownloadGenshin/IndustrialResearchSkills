# Official Source Policy

## Eligible sources

- Shanghai, Shenzhen, or Beijing Stock Exchange disclosure pages and document hosts.
- CNINFO disclosure pages and documents.
- The issuer's official periodic reports and official investor-relations website.

Use the latest official corrected or restated filing when multiple versions cover the same requested period. Record the original and correction relationship in the manifest.

## Ineligible sources for new values

- Wind terminal screenshots or exported third-party database tables.
- Brokerage, securities-research, sell-side, or investment-bank reports.
- News, portals, social media, data aggregators, or search-result snippets.

Existing ineligible screenshots in a template may remain untouched, but they cannot support newly entered values.

## Access boundary

Normal browser navigation, public cookies, redirects, and official download links are allowed. Do not bypass a CAPTCHA, login, paywall, robots restriction, rate limit, or other access control. If an official document remains inaccessible, try another eligible official host and otherwise mark the work unresolved.

Validate a downloaded file by HTTP status, content type when available, the `%PDF-` signature, and successful PDF parsing. Reject HTML error pages saved with a `.pdf` suffix.
